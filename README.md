This repo represents a successful experiment using CLAUDE CODE to convert the early stages of the prototype a Laravel project "platform2027" from using Livewire to using Inertia.js (React). 
This was done in several steps and took a few hours.

The project Platform 2027 conceived by Rudston Cullen is designed to digitally mirror the primary power structures that already govern the country in which it is to deployed. Although the initial focus is South Africa, it has been built with internationalisation in mind from the outset.

It has continued using Livewire instead of React, with the intention to build a separate mobile app at a later date.
